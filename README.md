# ResumeForge AI

ResumeForge AI is an AI-powered Resume Builder built using Flask.

## Features

- AI Summary Generation
- Resume Analysis
- ATS Score
- Live Resume Preview
- Resume Templates
- Save Resume
- Download PDF
- User Authentication
- Resume Dashboard
- Search Saved Resumes

## Tech Stack

Python
Flask
SQLite
HTML
CSS
JavaScript
Jinja2

## Installation

pip install -r requirements.txt

python app.py
